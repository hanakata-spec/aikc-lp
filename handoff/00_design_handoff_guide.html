Design Concept

02デザインコンセプト「招待状」

完全招待制という商材特性から、このLPは「売り込むLP」ではなく「高級会員制クラブの招待状」として設計しています。

  • 3色の世界観：墨黒（#16151A）× シャンパンゴールド（#C8A063）× 和紙＝生成り（#F5F1E8）。
  • 2書体の格：和文は明朝（Shippori Mincho）、英字・数字はローマン碑文体（Marcellus）。本文のみゴシック（Noto Sans JP）。
  • 引き算の美学：派手な装飾・AIっぽい青紫グラデ・過剰アニメーションを排し、静かな重厚感で品格を出す。装飾は金の罫線とアイコンに限定。

シグネチャー要素（このLPの顔）

① Hero 右端の縦書き「完全招待制」

writing-mode:vertical-rl による縦書きバッジ。上下に金の縦罫（::before/::after、height 54px）を配し、招待状の封緘のような格式を演出。768px 以下では横バッジ（.signature-badge）に切り替わる。

② Solution Bridge 図

5つの課題 → 1枚の招待状カード（β・¥50,000/月）→ 4つの価値へ、金線（#C8A063）で収束・展開するインラインSVG。「バラバラの打ち手を1つの会費に集約する」という提案の核を1枚で伝える。

CVR設計根拠（この判断がコンバージョンに効く）

① Hero＝単一突出スタッツ（¥50,000 のみ巨大）

価格 ¥50,000 を clamp(56px,9vw,120px) で巨大表示し、substats3個（1.5万人 / 1,100講座 / 100名超）は 15px と小さく添える。2,000LP を検証した DigitalApplied（2026）では、3バッジ均等配置（+9%）より単一突出（+18%）の方が高CVR。視線を1点に集中させる設計。

② 招待制の希少性（クロージング）

初版は「この資料をお渡ししている時点で、貴社はご紹介の対象です」を WHO と Final CTA に配置していたが、本LPは通常公開（検索・リンク流入あり）のため資料前提の文言は削除（2026-07-25・鈴木代表の指示）。希少性の提示は WHO の金枠招待パネル「完全招待制 — ご紹介と面談が必要です」に集約し、Final CTA は見出し「まずは、面談でお話ししましょう」で直接誘導する。この文言を復活させないこと。

③ 審査制・お断り条件の明示

WHO の「お断りする場合があります」は、会員制ビジネスの定石＝自己選別と希少性。誰でも入れないことが価値になり、申込者の質を上げる。

④ 価格分解（60→−18→42→月3.5万）

計算カードで「年会費60万→助成金−18万→実質42万→月3.5万」と段階分解。「回収できる経営投資」へ認識を転換させ、価格への抵抗を下げる。

⑤ FAQ は資料記載事実のみ（文言変更に注意）

FAQ6問はすべて営業資料PDFの記載事実に基づく。とくに Q2（解約条件）／Q3（助成金）／Q5（会食は非保証）は法的リスク回避のための表現。文言を変更する際は、コンプライアンス確認のうえで行うこと（安易な言い換えは景表法・不当表示リスクにつながる）。

Interaction

07インタラクション仕様

モーションは「静かに現れる」だけ。イージングは全体で cubic-bezier(.16,1,.3,1) に統一。

  • スクロール連動フェード：.reveal を IntersectionObserver で監視し .in を付与。opacity 0→1 ＋ translateY(24px→0)、0.8s cubic-bezier(.16,1,.3,1)。IO は threshold:0.12／rootMargin:'0px 0px -8% 0px'、一度表示したら unobserve（再生は1回のみ）。
  • Hero ロード時の段階フェード：.hero-el が @keyframes heroFade（0.9s cubic-bezier(.16,1,.3,1)、opacity0 + translateY(22px) から）。ディレイは d1 .05s / d2 .20s / d3 .35s / d4 .50s / d5 .65s / d6 .80s。
  • カード hover：.vcard / .tcard が translateY(-4px) ＋ 罫線を金に明化（.35s ease）。
  • CTA hover：.btn-primary の地が #D93A1B → #FB4113 ＋ translateY(-2px)（.25s）。.btn-ghost は文字・枠が --gold → --gold-bright。
  • スムーススクロール：html{scroll-behavior:smooth;scroll-padding-top:84px}。アンカー着地時にヘッダー分のオフセットを確保（※ヘッダー実高64pxに対し 84px の余白を取る設計）。
  • reduced-motion 配慮：@media (prefers-reduced-motion:reduce) で .reveal・.hero-el を強制表示（opacity:1;transform:none）、トランジション/アニメーションを無効化。JS側も同メディアクエリを検知し、その場合は全 .reveal に即 .in を付与（要素は最初から可視のまま）。IntersectionObserver 非対応環境も同様にフォールバック。

実装の勘所

JS は index.html 末尾の即時関数2つのみ（reveal 表示制御＋§11 の課題セルフチェック）。ライブラリ非依存。新しいセクションを追加する場合は要素に class="reveal" を付ければ自動でフェード対象になります。イージング値を変えるとサイト全体の「静けさ」が崩れるため、cubic-bezier(.16,1,.3,1) は維持推奨。

モック撮影の手順（Hero の高さ）

Hero の min-height:100svh は、フルページスクリーンショット撮影時のみ固定px（例：min-height:900px）に置換して撮影する。100svh のままだとキャプチャ環境のビューポート高でHeroが伸縮し、モックの再現性が崩れるため。撮影後は元に戻す。

11再構成追記（2026-07-25・SEO×CVR強化）

初版納品後、「Claude Code製LPがSEO検索1位」ノウハウ（①速い・素のHTML ②構造化データで信頼を機械に渡す ③低ハードルの診断型入口）を適用する再構成を実施しました。デザイン・コピー・セクション構成は不変で、以下5点が変わっています。

  1. 画像の3段fallback — 全画像に AVIF / WebP を追加し、<picture>（カード4枚）と image-set()（hero / Final CTA 背景）で AVIF→WebP→PNG の順に配信。画像転送量は実測 PNG 12.1MB → AVIF 288KB（−97.6%）。画像を差し替える際は必ず3形式を再生成してください: 
    ffmpeg -y -i 新画像.png -c:v libsvtav1 -crf 32 -preset 4 -still-picture 1 新画像.avif
ffmpeg -y -i 新画像.png -c:v libwebp -q:v 82 新画像.webp
  2. JSON-LD 構造化データ 4種（</head> 直前の @graph）— Organization / WebSite（alternateName で表記ゆれ対応）/ Service（Offer 月5万円）/ FAQPage。本文の FAQ・価格・社名を変更したら JSON-LD 側も必ず同期してください（特に FAQPage は本文と一字一句同一が原則）。
  3. Pain Strip を「経営課題 30秒セルフチェック」に — 5項目がタップで選択でき（role="checkbox"・キーボード対応）、該当数に応じて結果表示が3分岐（0件=既定の締め帯／1〜2件=標準CTA／3件以上=強調CTA）。aria-live で通知。資料請求より心理ハードルの低い入口を最前面に置く設計です。
  4. Hero 副CTA の文言変更 — 「クラブの中身を見る」→「30秒で課題チェック」（リンク先 #pain は同じ）。
  5. OGP / canonical / meta description 完備 — OGP画像は images/aiclub/ogp.png（1200×630・PNG。SVGはX/Slackで表示されないため不可）。canonical / og:url / og:image / JSON-LD の URL は仮ドメイン https://club.comix.co.jp/ のため、公開時に本番URLへ一括差し替えが必要です（該当箇所に HTML コメントあり）。

公開時にのみ効く項目

構造化データ・OGP・canonical は Web 公開後に検索エンジン/SNS が読むものです。ローカル確認では表示に影響しません。公開後は Google Search Console 登録 → 実データを見て FAQ 追記・表記ゆれ対応を続けるのが本ノウハウの後半戦です。
